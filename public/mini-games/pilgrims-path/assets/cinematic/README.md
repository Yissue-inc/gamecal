# 컷신 일러스트 교체 위치

여기에 `<id>.webp` 를 넣으면 게임이 코드로 그린 컷신 대신 그 이미지를 쓴다.
파일이 없으면 코드 렌더링으로 자동 폴백하므로, 한 장씩 올려도 된다.

권장 규격: **1280×720 · WebP · 400KB 이하**

| 파일명 | 장면 |
|---|---|
| `dream.webp` | 1장 · 불타는 도시를 등지고 선 소년 |
| `evangelist.webp` | 1장 · 전도자가 먼 빛을 가리킨다 |
| `pliable.webp` | 2장 · 유순이 늪에서 돌아선다 |
| `helphand.webp` | 2장 · 위에서 내려온 손 |
| `sinai.webp` | 3장 · 무너지는 산 |
| `wicket.webp` | 4장 · 화살비 속 좁은 문 |
| `cross.webp` | ★ 5장 · 짐이 굴러떨어진다 |
| `shining.webp` | 5장 · 빛나는 이 셋 |
| `apollyon.webp` | 8장 · 아볼루온과 마주 서다 |
| `valley.webp` | 9장 · 죽음의 그늘 골짜기 |
| `chariot.webp` | 10장 · 신실의 불수레 |
| `key.webp` | 11장 · 약속의 열쇠 |
| `celestial.webp` | ★ 12장 · 천성의 문 |

생성 프롬프트는 `docs/pilgrims-path-cinematic-art-spec.md` 참고.

# 컷신 · 스토리 어드벤처 확장 기획

> 질문: "픽셀게임의 한계를 넘어 완전한 스토리형 어드벤처로 가고 싶다.
> 어떤 장면에 어떤 어셋을 넣어야 극대화되나? 어셋을 여기서 바로 만들 수 있나?"

---

## 0. 어셋을 여기서 바로 만들 수 있나 — 정직한 답

**래스터 일러스트(그림 파일)는 이 세션에서 생성할 수 없다.** 이미지 생성 모델이 붙어 있지 않다.

그래서 세 가지를 대신 했다.

| | 무엇 | 상태 |
|---|---|---|
| 1 | **컷신 13컷을 코드로 그려서 지금 게임에 넣었다** | ✅ 완료 · 플레이 가능 |
| 2 | **일러스트를 넣으면 자동 교체되는 배선** | ✅ 완료 · 한 장씩 올려도 됨 |
| 3 | **Nano Banana/MJ 용 생성 프롬프트 13개** | ✅ 완료 · `gamecal/docs/pilgrims-path-cinematic-art-spec.md` |

즉 **기다릴 필요 없이 지금 컷신이 있는 게임을 플레이할 수 있고**,
CK가 이미 쓰는 파이프라인으로 그림이 나오는 대로 한 장씩 갈아 끼우면 된다.

교체는 파일을 넣는 것이 전부다. 코드 수정도, 배포 설정도 없다.

```
public/mini-games/pilgrims-path/assets/cinematic/cross.webp   ← 넣으면 끝
```

## 1. 코드 컷신의 아트 디렉션 — 왜 실루엣인가

코드로 사람 얼굴을 그리면 반드시 어색해진다. 그래서 **역광 실루엣**으로 갔다.

- 모든 컷이 "빛을 향해 선 사람"의 구도다 — 천로역정의 주제 그 자체다
- 얼굴을 그리지 않으므로 어색해질 여지가 없다
- 실루엣 + 빛 + 대기 입자만으로 감정이 전달된다

이건 타협이 아니라 **선택한 스타일**이다. 일러스트로 교체하더라도
같은 구도 언어를 유지하면 두 종류가 섞여도 이질감이 없다.

## 2. 13컷 — 어디에 왜 넣었나

컷신은 "많이"가 아니라 **감정이 꺾이는 지점에만** 넣었다. 장당 1컷 원칙.

| # | 장 | 컷신 | 왜 여기인가 |
|---|---|---|---|
| 1 | 멸망의 도시 | `dream` | 게임의 첫 인상. 등에 진 짐과 불타는 도시를 한 화면에 |
| 1 | 〃 | `evangelist` | 목표가 처음 생기는 순간 ("저 빛") |
| 2 | 낙담의 늪 | `pliable` | 동행자를 잃는다 — 혼자가 되는 첫 경험 |
| 2 | 〃 | `helphand` | 스스로 못 나온다는 것을 인정하는 순간 |
| 3 | 세속 현자 | `sinai` | 지름길의 대가를 몸으로 안다 |
| 4 | 좁은 문 | `wicket` | 맞으면서도 두드린다 |
| **5** | **십자가** | **`cross`** | **★ 게임 전체의 정점.** 짐이 떨어지고 조작이 바뀐다 |
| 5 | 〃 | `shining` | 옷·표·두루마리를 받는다 |
| 8 | 겸손의 골짜기 | `apollyon` | 처음으로 도망칠 수 없는 적 |
| 9 | 죽음의 그늘 | `valley` | 속삭임이 내 생각이 아니라는 것 |
| 10 | 허영의 시장 | `chariot` | 신실의 죽음 — 이 게임에서 가장 무거운 장면 |
| 11 | 의심의 성 | `key` | 6장 동안 갖고 있었다는 깨달음 |
| **12** | **천성** | **`celestial`** | **★ 끝** |

**의도적으로 넣지 않은 곳**: 6장(곤고산), 7장(궁전). 두 장은 각각 등반과 마을이라
호흡을 쉬어 가는 구간이다. 여기에 컷신을 넣으면 정점이 흐려진다.

## 3. 여기서 더 갈 수 있는 것 — 우선순위 순

### A. 대사 초상화 (효과 대비 비용이 가장 좋다)
지금 대화 초상화는 픽셀 스프라이트를 잘라 쓴다. `_bible-shared` 처럼
**인물별 클로즈업 일러스트**를 넣으면 JRPG 감성이 한 단계 올라간다.

우선순위: 크리스천(4단계: 짐/옷/검/갑주) → 아볼루온 → 전도자 → 절망 거인 → 신실 → 소망

감정 변주까지 가면 인물당 2~3장. 6명 × 2 = 12장이면 체감이 크게 달라진다.

### B. 장 도입 아이캐치
각 장 시작 시 제목 카드 뒤에 그 장의 **분위기 컷** 한 장.
컷신보다 가볍고(정지 화면 2초) 12장 전체의 결을 잡아 준다.

### C. 컷신 간 전환
지금은 페이드. 일러스트가 들어오면 **가로 와이프 / 디졸브**가 더 어울린다.
`Cinema.draw` 의 페이드 구간만 바꾸면 된다.

### D. 보이스
캡션이 이미 한/영으로 분리되어 있어 오디오를 붙이기 쉽다.
전체 낭독은 과하고, **★ 두 컷(`cross`, `celestial`)만** 해도 효과가 크다.

### E. 분기 엔딩 컷
신실도에 따라 엔딩 랭크가 4단계인데 지금은 텍스트로만 다르다.
`celestial` 변주 2장(빛의 양이 다른)만 만들어도 다회차 이유가 생긴다.

## 4. 만약 전면 일러스트 게임으로 간다면

지금 구조는 그 방향으로 열려 있다.

- 컷신 = 이미 이미지 교체 지원
- 초상화 = `makePortrait()` 한 함수만 이미지 로딩으로 바꾸면 됨
- 배경 = `makeBackdrop()` 이 레이어 배열을 돌려주므로, 레이어별 PNG 로 대체 가능
- 스프라이트 = 여기만 대공사다. 픽셀 캐릭터를 유지하고 컷신·초상화만 일러스트로 가는
  **하이브리드가 비용 대비 효과가 가장 좋다** (옥토패스 트래블러, 크로노 트리거가 이 구조다)

권장: **스프라이트는 픽셀로 두고, 컷신·초상화·배경만 일러스트로.**
전부 일러스트로 바꾸면 지금의 조작감과 성능(360KB, 로딩 0초)을 잃는다.
